Intro) 왜 이 코스를 하나?

목표는 "AI 기능 구경"이 아니라 "우리 환경에 맞게 AI를 도입하고 운영하는 실행력"을 만드는 것입니다.

  • 노베이스도 시작 가능
  • 작은 성공 -> 확장 전략
  • 사람 검토를 유지하는 운영 방식

Chapter 1) 기본 용어와 운영 원칙

핵심 용어

  • 프롬프트, LLM, API, 워크플로우
  • 평가 단계(실행 -> 소규모 -> 전체)
  • 사람 검토(Human-in-the-loop)

운영 원칙

  • 변수는 한 번에 하나만 변경
  • 실패 사례를 기록하고 반복 개선
  • 최종 배포 전 검토 절차 고정

Chapter 2) AI 도입 가능 영역 분해

각 영역에서 AI 역할과 사람 역할을 분리하면 도입 실패가 줄어듭니다.

영역 AI 역할 사람 역할
문서/콘텐츠 초안 생성, 요약, 구조화 사실 검증, 표현 최종 확정
프로젝트 관리 액션아이템/기한 추출 우선순위 결정, 책임자 지정
개발/연동 응답 정리, 에러 안내 예외 처리, 운영 기준 확정
운영/거버넌스 로그 기록, 마스킹 자동화 정책 승인, 감사 대응

Chapter 3) 실행 매트릭스 (Do / Don't / Owner)

Do

  • 도입 영역 1~2개부터 시작
  • AI 결과는 초안으로 처리
  • 책임자(Owner)를 명시

Don't

  • 고위험 의사결정 즉시 자동화
  • 근거 검증 없이 결과 배포
  • 실패 원인 기록 생략

상세 문서: docs/ko/ai-adoption-execution-matrix.md

Chapter 5) 연동과 서비스화

백엔드

  • 프롬프트 라우팅 규칙
  • 에러/타임아웃 처리
  • 요청/응답 로깅

프론트

  • 입력 -> 결과 -> 재시도 흐름
  • 히스토리 저장
  • 사람 검토 확인 UI

Chapter 6) 모바일 트랙

시나리오

  • 음성 회의록 생성
  • 사진 OCR 요약
  • 현장 즉시 Q&A

운영 원칙

  • 짧은 입력 템플릿
  • 3줄 요약 -> 상세보기
  • 민감정보 마스킹 고정

End) 마무리 및 다음 액션

완주 후에는 신규 도입보다 안정화 우선순위를 정하고 다음 사이클 계획으로 넘어갑니다.

완주 체크

  • 도입 영역 1개 이상 운영 시작
  • 실패 사례와 대응책 문서화
  • 책임자별 후속 액션 정의
