AI 도입 실전 웹교재

노베이스도 따라올 수 있도록, AI를 어디에 어떻게 도입할지 영역별로 학습하는 실행형 교재입니다.

학습 시작 실행 매트릭스 보기
커리큘럼 도입 영역 분해 1페이지 매트릭스 주간 실행 모바일 트랙

1) 단계별 커리큘럼

Step 1: 문서 자동화

  • 회의록/보고서/발표본 템플릿 만들기
  • 요약/교정/톤 변환 프롬프트 만들기
  • 사실성/누락/표현 체크리스트 운영

Step 2: 프로젝트 관리 자동화

  • 회의 메모 -> 액션아이템 자동 추출
  • 담당자/기한/우선순위 구조화
  • 주간 진행 리포트 자동화

Step 2.5: 브릿지

  • 노코드/로우코드로 AI 호출 흐름 체험
  • 입력 -> JSON 출력 구조 확인
  • 실패 케이스와 재시도 전략 기록

Step 3: API 연동

  • 프롬프트 라우팅과 응답 스키마 정의
  • 에러 처리와 요청 로그 설계
  • 프론트 입력/결과/히스토리 화면 구성

2) AI 도입 가능 영역 세부 분해

점수보다 "도입 위치"에 집중합니다. 각 영역에서 AI 역할과 사람의 최종 검토 지점을 분리해 설계합니다.

영역 AI가 맡는 역할 사람이 최종 확인할 것
수업/업무 설계 목표 문장 초안, 차시 구조 자동 제안 학습자 수준 적합성, 교육과정 정합성
콘텐츠 제작 교안/실습자료/예시 초안 생성 사실 오류, 난이도 과부하 여부
프로젝트 관리 액션아이템/담당/기한 추출 실행 가능성, 책임 공백 여부
개발/연동 응답 구조화, 실패 복구 안내 핵심정보 손실, 예외 처리 누락
운영/거버넌스 민감정보 마스킹, 로그 기록 자동화 정책 준수, 책임 추적 가능성
모바일 활용 음성/사진 입력 구조화, 즉시 요약 인식 오류, 문맥 누락

3) 1페이지 실행 매트릭스

Do

  • 작은 범위부터 시작
  • AI 결과는 초안으로 취급
  • 실패 사례를 다음 반복에 반영
  • 영역별 책임자(Owner) 명확화

Don't

  • 고위험 의사결정에 즉시 연결
  • 근거 확인 없이 결과 배포
  • 책임자 없는 운영
  • 효과 검증 없는 툴 추가

상세 매트릭스 문서: docs/ko/ai-adoption-execution-matrix.md

4) 주간 실행 체크리스트

체크 상태는 브라우저에 저장됩니다(로컬 저장).

5) 모바일 AI 활용 트랙

대표 시나리오

  • 음성 -> 텍스트 회의록 변환
  • 사진 OCR -> 요약/정리
  • 이동 중 3줄 요약 검토
  • 현장 질의응답

운영 포인트

  • 짧은 입력형 템플릿 사용
  • 요약 -> 상세보기 구조 유지
  • 민감정보 입력 시 마스킹
  • 즉시 피드백 후 사람 검토 고정
