# AI Toolbox & Learning Hub 🚀

**AI Toolbox** is a modern, interactive web platform designed to help students, educators, and researchers discovery the best AI tools for their needs and learn how to use them effectively.

![Project Screenshot](https://via.placeholder.com/800x400?text=AI+Toolbox+Preview)

## ✨ Key Features

### 1. 🎯 Interactive Tool Wizard
- Finds the perfect AI tool based on your **Role** (Student, Educator, Researcher) and **Goal** (Writing, Coding, Design, Video, Music).
- tailored recommendations with direct links to tools like ChatGPT, Perplexity, Cursor, Midjourney, Runway, and Suno.

### 2. 🧪 Interactive Prompt Lab (with Real AI)
- A dark-mode code editor environment to practice prompt engineering.
- **Simulation Mode**: Provides heuristic feedback without an internet connection.
- **Real AI Mode (Gemini)**: Connect your own Google Gemini API Key to get live, intelligent feedback and auto-optimization.
- **Typewriter Effect**: Watch the AI "write" the improved prompt step-by-step.

### 3. 🎓 Onboarding Learning Hub
- **Chapter 1 (Basics)**: Learn the **RTF** (Role, Task, Format) formula.
- **Chapter 2 (Advanced)**: Master the **CO-STAR** framework and techniques like Chain of Thought.
- **Chapter 3 (Role-Specific)**: Tips for developers and researchers.

### 4. 🎨 Premium UI/UX
- Fully responsive design with **Dark/Light Mode**.
- Clean, SaaS-style aesthetic using Pretendard font and SVG icons.

## 🛠️ Tech Stack
- **HTML5 / CSS3**: Modern Flexbox/Grid layouts, CSS Variables for theming.
- **JavaScript (Vanilla)**: DOM manipulation, `localStorage` for settings, and async API calls.
- **Gemini API**: Integrated for live prompt analysis.

## 🚀 How to Run Locally
1. Clone the repository.
2. Open `ai_resources.html` or `onboarding.html` in your browser.
3. To use Real AI features, click the **Settings (⚙️)** button and enter your Gemini API Key.
