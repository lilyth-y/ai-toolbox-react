# 2분 수동 스모크 테스트 (사용자 클릭 시나리오 5개)

목적: 배포된 웹페이지가 사용자 관점에서 정상 동작하는지 빠르게 확인한다.  
기준 URL: `https://lilyth-y.github.io/ai-toolbox-react/`

---

## 시나리오 1) 홈 진입 및 핵심 페이지 이동

1. 홈(`index.html`) 접속
2. 아래 페이지로 각각 이동
   - `ai_resources.html`
   - `ai_textbook.html`
   - `smallbiz_ai_guide.html`

기대 결과:
- 각 페이지가 오류 없이 열린다.
- 링크 클릭 시 404 없이 정상 이동한다.

---

## 시나리오 2) 웹교재 테마 토글 + 유지 확인

1. `ai_textbook.html`에서 우상단 테마 버튼(🌓) 클릭
2. 다크/라이트 전환 확인
3. 새로고침(F5) 후 테마 유지 확인

기대 결과:
- 테마가 즉시 전환된다.
- 새로고침 후에도 마지막 테마 상태가 유지된다.

---

## 시나리오 3) 웹교재 체크리스트 저장 + 진행률 반영

1. `ai_textbook.html`에서 챕터 완료 체크 2~3개 클릭
2. 상단 진행률(%), 다음 권장 단계 문구 변화를 확인
3. 새로고침 후 체크 상태 유지 확인

기대 결과:
- 체크 즉시 진행률이 반영된다.
- 새로고침 후 체크 상태가 복원된다.

---

## 시나리오 4) 소상공인 가이드 업종 URL 공유 동작

1. `smallbiz_ai_guide.html?industry=cafe` 접속
2. 탭을 `소매(retail)`로 변경
3. "현재 업종 링크 복사" 버튼 클릭
4. 새 탭에서 붙여넣기 접속

기대 결과:
- 업종 탭 변경 시 프롬프트가 해당 업종 내용으로 바뀐다.
- 복사된 URL에 `?industry=...`가 포함된다.
- 새 탭 접속 시 같은 업종 상태로 열린다.

---

## 시나리오 5) 소상공인 체크리스트 저장 확인

1. `smallbiz_ai_guide.html`에서 각 장 체크박스 1개씩 선택
2. 페이지 새로고침
3. 체크 상태 유지 여부 확인

기대 결과:
- 체크박스 상태가 새로고침 후에도 유지된다.
- 반복 클릭 시 상태가 정상 반영된다.

---

## 실패 시 빠른 분기

- 페이지가 열리지 않음: Pages 배포 상태 및 URL 오타 확인
- 체크/테마가 유지되지 않음: 브라우저 localStorage 차단 여부 확인
- 업종 URL 공유 불일치: 쿼리 파라미터(`industry`) 값 유효성 확인 (`cafe`, `restaurant`, `retail`, `service`)
