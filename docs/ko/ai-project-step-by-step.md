# AI로 할 수 있는 일: Step-by-Step 프로젝트 가이드

이 문서는 **AI를 활용해 어떤 일을 할 수 있는지**를 초보자도 이해할 수 있도록 단계별로 설명하는 프로젝트용 안내서입니다.  
목표는 다음 3가지입니다.

1. 문서 작성부터 프로젝트 관리까지 실무 흐름을 한 번에 보여주기
2. 모델 "사용"을 넘어 간단한 모델 "개발/연동"까지 확장하기
3. 데스크톱뿐 아니라 **모바일 환경에서의 AI 활용법**도 별도로 안내하기

---

## 0) 완전 초보(노베이스)를 위한 시작점

### 0-1. 먼저 이해할 핵심 용어 6개
- **프롬프트(Prompt)**: AI에게 내리는 지시문
- **LLM**: 긴 문장을 이해/생성하는 언어 모델
- **워크플로우**: 일을 처리하는 순서(예: 기획 -> 작성 -> 검토 -> 배포)
- **API**: 앱과 AI 서비스를 연결하는 인터페이스
- **모델 학습(Fine-tuning 포함)**: 데이터로 모델 성능을 개선하는 과정
- **평가 지표(Metric)**: 결과 품질을 수치로 확인하는 기준

### 0-2. 프로젝트 운영 원칙
- 처음에는 "정확도 100%"보다 "재현 가능한 절차"를 우선합니다.
- 실험 시에는 한 번에 변수 하나만 바꿉니다.
- "작동 확인 -> 소규모 검증 -> 전체 평가" 순으로 진행합니다.

---

## 1) 카테고리 체계 (기초 -> 심화 순 정렬)

아래 카테고리는 **난이도와 구현 복잡도 기준**으로 정렬되어 있습니다.

| 순서 | 카테고리 | 핵심 질문 | 산출물 예시 |
|---|---|---|---|
| 1 | 문서 작성 자동화 | AI로 글쓰기/요약/번역을 어떻게 빠르게 할까? | 회의록, 요약 리포트, 초안 문서 |
| 2 | 프로젝트 관리 자동화 | 일정을 어떻게 구조화하고 추적할까? | 백로그, 우선순위 보드, 주간 리포트 |
| 3 | 지식/자료 운영 | 산재된 정보를 어떻게 검색 가능하게 만들까? | FAQ, 내부 위키, 검색형 문서 |
| 4 | 업무 보조 도구 제작 | 반복 작업을 AI로 어떻게 줄일까? | 자동 메일 작성기, 분류 스크립트 |
| 5 | 모델 활용 애플리케이션 | 기존 모델을 서비스에 어떻게 연동할까? | 챗봇, 추천 도우미, API 기반 기능 |
| 6 | 모델 개발/개선 | 우리 문제에 맞는 모델을 어떻게 만들까? | 도메인 특화 모델, 평가 리포트 |
| 7 | 모바일 AI 활용 (별도 트랙) | 이동 중/현장에서 AI를 어떻게 쓸까? | 모바일 실습 가이드, 앱 운영 체크리스트 |

---

## 2) 단계별 실행 가이드

## Step 1. 문서 작성 자동화
### 목표
- 개인/팀 문서 생산 시간을 줄이고 품질 편차를 낮춥니다.

### 구현 항목
- 문서 템플릿 정의(보고서, 회의록, 기획서)
- 프롬프트 템플릿 정의(요약, 교정, 톤 변환)
- 결과 검토 체크리스트(사실성, 누락, 표현)

### 데모 과제
- 같은 내용을 "요약본/상세본/발표본"으로 자동 변환

---

## Step 2. 프로젝트 관리 자동화
### 목표
- AI로 태스크 쪼개기, 우선순위화, 상태 리포팅 자동화

### 구현 항목
- 이슈/작업 단위 템플릿 설계(목표, 완료 기준, 담당자)
- 주간 진행률 요약 자동 생성
- 리스크/블로커 추출 자동화

### 데모 과제
- 회의 메모를 입력하면 "실행 항목 + 담당자 + 마감일" 자동 추출

---

## Step 3. 기존 모델 연동형 서비스 만들기
### 목표
- API 기반으로 빠르게 사용자 기능을 제공합니다.

### 구현 항목
- 백엔드: 프롬프트 라우팅, 응답 캐싱, 에러 처리
- 프론트: 입력/결과 UI, 재생성 버튼, 히스토리 저장
- 운영: 사용량 제한, 실패 로그, 기본 안전 필터

### 데모 과제
- 사내 Q&A 도우미(문서 기반 답변 + 출처 링크)

---

## Step 4. 새로운 모델 생성/사용 예시  
### 예시 시나리오: "시험문제(주관식) 자동 채점 모듈 + 프론트 연동"

### 4-1. 문제 정의
- 입력: 학생의 주관식 답안
- 출력: 점수 + 근거 코멘트 + 개선 피드백
- 목표: 채점 일관성 향상과 피드백 시간 단축

### 4-2. 데이터 설계
- 샘플 데이터: `(문항, 모범답안, 채점기준, 학생답안, 정답점수)`
- 라벨 품질 확보: 최소 2인 이상 교차 검수 권장

### 4-3. 모델 전략
- 시작: 기존 LLM + 채점 루브릭 프롬프트
- 확장: 성능 부족 시 파인튜닝/추가 분류기 적용

### 4-4. 평가 단계 (권장)
1. **1단계(실행 검증):** 코드가 끝까지 정상 동작하는지 확인
2. **2단계(소규모 검증):** 작은 데이터셋에서 점수 일관성 개선 확인
3. **3단계(전체 평가):** 전체 데이터셋 기준 공식 성능 측정

### 4-5. 프론트 연동 데모
- 교사용 화면: 답안 목록, 자동 점수, 근거 보기, 수동 수정
- 학생용 화면: 점수, 피드백, 재학습 포인트 확인
- 관리자 화면: 문항별 오차율/분포 대시보드

### 4-6. 반드시 점검할 리스크
- 채점 편향(문체/길이에 따른 오판)
- 근거 없는 점수 설명(환각)
- 과목/학년이 달라질 때 일반화 실패

---

## 3) 모바일 환경에서 AI 활용 (별도 트랙)

모바일은 "짧은 입력, 빠른 확인, 현장 대응"에 강점이 있습니다.

### 3-1. 모바일 우선 사용 시나리오
- 음성 -> 텍스트 회의록 변환
- 이동 중 요약 확인 및 승인
- 사진 기반 정보 추출(OCR + 정리)
- 현장 질의응답(매뉴얼/가이드 검색)

### 3-2. 모바일 UX 설계 포인트
- 긴 프롬프트 대신 **선택형 템플릿 버튼** 제공
- 결과는 3줄 요약 -> 펼쳐보기 구조로 제공
- 네트워크 불안정 대비 재시도/임시저장 필수
- 개인정보 포함 입력 시 자동 마스킹 처리

### 3-3. 추천 데모 구성
- "모바일 채점 보조" 앱
  - 카메라로 답안 촬영
  - OCR 후 자동 채점 요청
  - 교사가 점수/피드백 즉시 확인 및 수정

---

## 4) 프로젝트 산출물 체크리스트

- [ ] 카테고리별 가이드 문서(초급/중급/심화)
- [ ] 프롬프트 템플릿 모음
- [ ] 샘플 데이터셋 및 평가 스크립트
- [ ] 백엔드 API 명세서
- [ ] 프론트 시연 페이지(웹/모바일)
- [ ] 실패 사례/한계/향후 계획 문서

---

## 5) 권장 진행 순서 (빠른 실행 버전)

1. 문서 자동화 데모 완성  
2. 프로젝트 관리 자동화 데모 완성  
3. API 연동형 기능 1개 완성  
4. 주관식 채점 POC(작은 데이터셋) 구현  
5. 웹 프론트 연동 -> 모바일 최적화 순으로 확장

---

## 6) 결론

이 프로젝트의 핵심은 "AI 기능 나열"이 아니라,  
**실제 업무/학습 흐름에 맞게 단계별로 설계하고 검증하는 것**입니다.

초보자는 Step 1~2만으로도 즉시 효과를 체감할 수 있고,  
중급 이상은 Step 4를 통해 모델 개발과 서비스 연동까지 확장할 수 있습니다.
